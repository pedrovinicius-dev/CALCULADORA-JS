# Calculadora Web - Protótipo (v1.0)

Este é um projeto prático que desenvolvi para aprimorar meus conhecimentos fundamentais em desenvolvimento frontend. O foco principal desta aplicação foi exercitar a integração entre a interface de usuário (HTML/CSS) e a manipulação do DOM utilizando JavaScript.

## 📌 Status do Projeto
A aplicação encontra-se em sua primeira versão de desenvolvimento. Optei por documentar o estado atual do software diretamente na interface, deixando claro o que já está funcional e o que está mapeado para as próximas atualizações. O objetivo atual foi validar a estrutura visual e a lógica inicial de eventos.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica dos elementos.
* **CSS3:** Estilização da interface e organização do layout utilizando propriedades de alinhamento.
* **JavaScript:** Lógica de cálculo, gerenciamento de estado das variáveis e eventos de clique.

## ✨ Funcionalidades Implementadas
* Interface gráfica segmentada entre painel de informações e área interativa.
* Resolução de operações matemáticas fundamentais de soma e subtração.
* Suporte no visor para o retorno de números negativos como resultado válido de uma equação.
* Botão de limpeza (C) para redefinição da memória e do visor.

## 🚧 Próximos Passos
Como registro do meu processo de aprendizado, mapeei os seguintes pontos de melhoria que serão implementados nos próximos commits:
* **Operações múltiplas:** Expandir a lógica para suportar cálculos contínuos. Atualmente, o sistema processa de forma otimizada dois números por operação (ex: "212 + 345").
* **Entrada de valores negativos:** Habilitar a inicialização de uma operação a partir de um número negativo digitado pelo usuário.
* **Expansão de operadores:** Implementar as funções de multiplicação e divisão.
* **Refatoração de Código:** Otimizar o arquivo JavaScript, ao agrupar elementos e reduzir a repetição na captura dos botões de interface.
